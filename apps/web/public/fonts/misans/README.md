# MiSans VF

Source package: `misans@5.0.0`, `lib/Normal/MiSansVF.min.css`.

The 56 WOFF2 files are unmodified files referenced by that stylesheet.
The font-face declarations in `../../../src/fonts/misans.css` preserve its
Unicode ranges and variable weight range (150–700), using local asset URLs.
Browsers request only the Unicode ranges needed by the current text.
